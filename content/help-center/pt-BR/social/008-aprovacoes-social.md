Aprovações organizam a decisão sobre uma **versão específica** do conteúdo ou criativo. Abra **Social → Aprovações**.

## Fluxo de aprovação

1. Finalize o texto e a versão do criativo.
2. Envie essa versão para aprovação.
3. Acompanhe o pedido no inbox de Aprovações.
4. O responsável aprova, rejeita ou pede ajuste conforme as opções disponíveis.
5. Se houver ajuste, crie uma nova versão e envie um novo pedido.

## O que conferir no inbox

| Informação | Por que importa |
| --- | --- |
| Empresa | Evita decidir no contexto errado |
| Etapa do fluxo | Mostra se a decisão é interna ou do cliente |
| Status | Indica o próximo responsável |
| Versão | Garante que todos avaliam o mesmo arquivo |
| Histórico | Preserva decisões e respostas |

> **Importante:** uma aprovação não autoriza mudanças posteriores naquela versão. Se a mídia ou o texto mudar, envie a nova revisão para aprovação.

## Responder ao cliente

Use o campo de resposta do pedido quando disponível. Seja específico: indique o que mudou ou qual ponto precisa de decisão. Não coloque senha, token ou informação de outra empresa.

## Problemas comuns

| O que acontece | O que fazer |
| --- | --- |
| O pedido não aparece | Confira aba, filtros e empresa |
| A prévia é diferente da edição atual | O pedido aponta para uma versão anterior; envie a nova |
| Não consigo decidir | Seu papel pode ser apenas de acompanhamento |
| O cliente não vê | Confira acesso à Área do Cliente e estágio do fluxo |
| Há dois pedidos parecidos | Compare versão e data antes de responder |
