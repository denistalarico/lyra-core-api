As Automações são tarefas prontas que o Lyra executa para o negócio. A tela não é um construtor livre de fluxos: você escolhe uma receita disponível, completa a configuração e liga a chave.

## Onde fica

Abra **LeadFlow → Automações**. A lista mostra quantas estão ligadas e quais receitas estão disponíveis para o tipo de negócio selecionado.

## Como uma automação funciona

| Parte | Significado |
| --- | --- |
| Receita | O comportamento pronto, como follow-up ou distribuição |
| Gatilho | O evento que inicia a execução |
| Condições | O que precisa ser verdadeiro para continuar |
| Ações | O que o Lyra fará |
| Dependências | Canal, funil, etapa, usuário ou horário necessário |

## Ligar uma automação

1. Localize a receita na lista.
2. Ative a chave.
3. Se faltar informação, complete a **Configuração rápida**.
4. Revise os campos pendentes.
5. Salve e ligue.
6. Abra o detalhe quando precisar ver configuração, execução ou histórico.

> **[Owner/manager]** Ligar e editar automações muda o comportamento da operação. Faça um teste controlado antes de ampliar o uso.

Se a tela informar **As automações ainda não são executadas**, você pode configurar as receitas, mas elas só agirão quando a execução estiver liberada para o ambiente.

## Problemas comuns

| O que acontece | O que fazer |
| --- | --- |
| A chave não permanece ligada | Abra a configuração rápida e resolva os campos pendentes |
| Uma receita não aparece | Confira o tipo de negócio e os filtros |
| A automação está ligada, mas não age | Confira o aviso de runtime, o gatilho e as dependências |
| A lista parece incompleta | Limpe os filtros e clique em **Atualizar** |
| O resultado foi diferente do esperado | Desligue a receita e revise o histórico antes de religar |
