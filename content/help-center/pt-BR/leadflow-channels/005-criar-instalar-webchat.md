O Webchat cria um atendimento dentro do seu site e envia as conversas para o Inbox.

## Criar o widget

1. Abra **LeadFlow → Inbox → Configurações → Apps & Integrações → Webchat → Configurar**.
2. Clique em **Criar Webchat**.
3. Informe o nome interno, o título exibido e os dados de captura desejados.
4. Defina a aparência e os domínios onde o widget poderá funcionar.
5. Salve e publique.

> **[Owner/manager]** Criar, publicar, pausar ou excluir widgets exige acesso de gestão.

## Conferir antes de instalar

| Item | Pergunta de revisão |
| --- | --- |
| Identidade | Nome, título e cor combinam com a marca? |
| Captura | O formulário pede somente os dados necessários? |
| Domínios | O domínio real do site está autorizado? |
| Estado | O widget está **Ativo**, não em rascunho ou pausado? |

## Instalar e testar

1. Abra o widget criado e copie o código de instalação exibido.
2. Adicione o código ao site conforme a ferramenta usada pelo site.
3. Publique a alteração do site.
4. Volte à lista de widgets e use **Testar conexão**.
5. Abra o site em uma janela anônima e envie uma mensagem de teste.
6. Confirme a conversa em **LeadFlow → Inbox**.

Na lista, **Configurar** abre o widget; **Renomear**, **Atualizar**, **Testar**, **Pausar/Retomar** e **Remover** cuidam do ciclo de vida.

## Problemas comuns

| O que acontece | O que fazer |
| --- | --- |
| O widget não aparece | Confirme publicação, código instalado e domínio autorizado |
| O teste mostra domínio restrito | Adicione o domínio correto e publique novamente |
| O widget aparece, mas não recebe | Use **Testar conexão** e confira o Inbox da empresa selecionada |
| Mudanças não aparecem no site | Salve, publique e limpe o cache da página |
| O agente não responde | Ligue o Webchat ao agente e revise a regra de ativação |
